# 📖 Deskripsi

**SIZINUS (Simulasi Perizinan Usaha)** merupakan aplikasi pembelajaran berbasis Android yang dirancang untuk membantu pelaku **Usaha Mikro, Kecil, dan Menengah (UMKM)** memahami proses legalitas usaha secara interaktif, adaptif, dan terstruktur.

Aplikasi ini dikembangkan sebagai media edukasi dengan mengintegrasikan:

- 🎮 **Gamification** menggunakan **Octalysis Framework**
- 🌳 **Rule-Based Decision Tree** untuk rekomendasi perizinan
- 📚 **Adaptive Learning Path** untuk jalur pembelajaran yang menyesuaikan progres pengguna

Melalui pendekatan tersebut, pengguna tidak hanya mempelajari tahapan perizinan usaha, tetapi juga memperoleh pengalaman belajar yang lebih menarik melalui sistem poin, level, badge, misi, dan leaderboard.

---

# 🎯 Tujuan Aplikasi

SIZINUS bertujuan membantu pelaku UMKM:

- memahami proses legalitas usaha
- mengetahui izin usaha yang diperlukan
- mempelajari tahapan perizinan secara bertahap
- meningkatkan motivasi belajar melalui gamifikasi

# ✨ Fitur Utama

## 🏠 Dashboard
- Ringkasan perkembangan belajar
- Progress pembelajaran
- Level pengguna
- XP
- Statistik pencapaian

## 📝 Simulasi Perizinan

- Simulasi proses pembuatan izin usaha
- Formulir bertahap (Stepper)
- Validasi data setiap tahap
- Penyimpanan progress otomatis

## 🌳 Rekomendasi Perizinan

Menggunakan **Rule-Based Decision Tree** untuk menghasilkan rekomendasi izin berdasarkan karakteristik usaha pengguna.

## 📚 Panduan Usaha

Menggunakan **Adaptive Learning Path** sehingga materi diprioritaskan sesuai:

- hasil simulasi
- rekomendasi izin
- progres pembelajaran

## 🎮 Gamifikasi

Penerapan **Octalysis Framework** melalui:

- ⭐ Experience (XP)
- 🏅 Badge
- 📈 Level
- 🎯 Mission
- 🏆 Leaderboard
- 📜 Riwayat Aktivitas

# 📚 Panduan Penggunaan

## 1️⃣ Registrasi

- Buka aplikasi
- Pilih **Daftar**
- Isi data pengguna
- Klik **Register**

## 2️⃣ Login

- Masukkan email
- Masukkan password
- Klik **Masuk**

## 3️⃣ Memulai Simulasi

- Pilih menu **Simulasi**
- Isi data usaha
- Ikuti seluruh tahapan
- Selesaikan simulasi

## 4️⃣ Melihat Rekomendasi

Setelah simulasi selesai:

- buka menu **Rekomendasi**
- sistem akan memberikan rekomendasi izin usaha yang sesuai

## 5️⃣ Mempelajari Panduan

Masuk ke menu **Panduan Usaha**

Materi akan muncul secara otomatis sesuai hasil simulasi dan progres belajar.

## 6️⃣ Menyelesaikan Misi

Selama belajar pengguna akan memperoleh:

- XP
- Badge
- Level
- Posisi Leaderboard
